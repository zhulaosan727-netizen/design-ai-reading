分享：智能体，来见见 Figma 画布

我们正在快速改进 Figma 对 AI 智能体的支持。该功能最终将成为按用量付费的功能，但在 beta 测试期间目前可免费使用。

从色板、按钮内边距，到排版和交互，设计决策一直决定着产品的成型方式。无论多么微小，这些决策都会不断累积，让你的产品和用户体验从众多同类中脱颖而出。迄今为止，AI 智能体一直缺乏这些上下文，这也是为什么许多由 AI 生成的设计常常显得陌生而千篇一律。

你可以在代码与画布之间自如切换，智能体则在同一个共享上下文中工作。而技能（skills）——一组以 markdown 文件编写的指令——现在可以直接塑造智能体在 Figma 画布上的构建方式。这些专业经验会指导每一份产出，其价值比以往任何时候都更高。

用技能指导你的智能体

在代码与画布之间协同工作

我们现有的 generate_figma_design 工具可将线上应用和网站中的 HTML 转换为可编辑的 Figma 图层。全新的 use_figma 工具则让智能体能够基于你的设计系统在画布上操作，这是 Figma 智能体工作流迈出的一大步。

这两个工具相辅相成。当设计与代码不同步时，generate_figma_design 会把最新的 UI 带入 Figma 进行迭代。之后，use_figma 可以使用你的组件和变量来编辑这些设计，或创建新的资产。

向 AI 智能体开放画布，意味着它们可以访问你的设计系统和文件。而技能则定义了智能体如何使用这些访问权限。技能规定了工作流在 Figma 中如何执行：该采取哪些步骤、遵循怎样的顺序、遵守哪些约定。除了工作流本身，技能还确保智能体拥有所需的专业知识和上下文，从而产出持久耐用、符合品牌调性的设计，并清楚什么才是好的设计。技能弥合了知识鸿沟，让智能体知道如何在 Figma 中工作。“最好的产品出自那些高度重视细节的团队，”Claude Code 产品负责人 Cat Wu 说道。“许多设计团队在 Figma 中打磨作品，再借助 Claude Code 将产品变为现实。技能教会 Claude Code 如何直接在设计画布上工作，让你构建出的产品始终忠实于团队的意图与判断。”

任何人都可以编写技能，而且无需开发插件或编写代码。今天发布的多个技能来自社区中的从业者，他们正在构建这些工作流，并在实践中定义什么是出色的设计。其核心是一个基础的 Figma 技能 /figma-use，所有其他技能都以它为基础。它让智能体对 Figma 的运作方式形成共同的理解，从结构到核心原则。团队随后可以对这项能力进行定制和迭代，以塑造智能体的工作方式。

以下是九个你现在就可以探索的示例技能：

  • /figma-generate-library：根据代码库在 Figma 中创建新组件
  • /figma-generate-design：使用现有组件和变量在 Figma 中创建新设计
  • /create-voice：根据 UI 规格说明生成屏幕阅读器规格说明（VoiceOver、TalkBack、ARIA）（Ian Guisard，Uber）
  • /cc-figma-component：根据结构化 JSON 契约生成 Figma 组件 （Nick Villapiano，One North）
  • /apply-design-system：将现有设计与设计系统组件关联 （Chris Goebel，Edenspiekermann）
  • /rad-spacing： 使用变量和兜底方案应用层级化间距（Nolan Perkins，Rad Collab）
  • /edit-figma-design：使用 Warp 和 Oz 编排 Figma 设计工作流 （Warp）
  • /sync-figma-token：在代码与 Figma 变量之间同步设计令牌（design token），并支持漂移检测 （Firebender）
  • /multi-agent：在 Augment 中运行并行工作流并实现设计（Augment Code）

我们的内置技能会向智能体展示如何在 Figma 画布上工作。

技能不只是定义你与智能体协作时要构建什么，还会通过自我修复循环来塑造产出的打磨方式。智能体生成一个界面后，可以截取屏幕截图，并对不匹配的地方进行迭代。由于它操作的是真实的结构、组件、变量和自动布局，这些调整会作用于系统本身，而不只是视觉输出。

AI 模型天生具有不确定性，同样的提示词可能产出不同的结果。技能通过固化具体的步骤、准则和代码，让这种行为更可预测。你的规范不再是静态文档，而是智能体在工作时遵循的规则，并通过你已定义好的组件、变量和结构得以落实。
