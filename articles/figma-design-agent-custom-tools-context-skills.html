为每次对话带来更多上下文

好的上下文不只是为智能体提供信息，还会影响它的产出。智能体越贴近你的项目、品牌和工作方式，输出就越精准。

  • 直接附加文件：把用户访谈、UX 文案文档或数据报告等文件拖入智能体对话。智能体会在整个对话中将其作为参考，让产出体现你的项目上下文与方向。
  • 引用其他 Figma 文件：粘贴 Figma 文件链接后，智能体会获得完整结构——组件、Token、布局和样式——从而理解并复现设计模式，而不是只能从一张扁平图片中大致模仿。
  • 联网搜索：智能体无需离开 Figma 就能获取实时数据，例如为房源列表获取真实的餐厅名称和照片、竞品当前的 UX 模式，以及用于逼真视觉稿的最新内容。
  • 连接你的工具：MCP（模型上下文协议）连接器可将 GitHub、Atlassian、Slack 等工具中的上下文直接带入智能体，还能把更新回传到这些工具。你可以从 Linear 拉取产品工单来指导设计，也可以引用 Hex 中的数据，无需复制粘贴。

放大你的设计观点

好的提示词承载着一种观点。Skills 让你保存这些思考，与团队共享，并让你的创意方向超越自己的文件，发挥更大作用。

  • 创建自定义 Skills：Skills 能把你反复使用的提示词变成可复用的斜杠命令，无论是应用特定美学风格、评审设计，还是自动化你已经摸索出的流程。
  • 向团队发布 Skills：分享一个 Skill，你的思考就成为整个团队工作方式的一部分。设计理念、标志性美学、反馈视角，都能变成任何队友可以实践、学习并在此基础上继续构建的东西。
  • 查看协作者的提示词：迭代历史不只是一份记录，更是了解他人思考方式的窗口。智能体对话默认对文件协作者可见，让整个过程成为共享资源。需要时，你也可以随时将其设为私密。
