通过提示词获得更好的输出

Claude 对设计原则、排版和色彩理论有扎实的了解，但除非明确鼓励，否则它默认会做出稳妥的选择。经过反复实验，我们发现有三种策略可以稳定地带来更好的结果：

  1. 引导具体的设计维度 - 分别引导 Claude 关注排版、色彩、动效和背景
  2. 参考设计灵感 - 建议 IDE 主题或文化美学等来源，但不要规定得过于死板
  3. 点明常见的默认做法 - 明确告诉 Claude 避免其倾向的通用化选择

下面的提示词将这些策略应用到了四个关键设计领域。

提示词

要应用这些调整，你可以将这段提示词追加到系统提示词或 CLAUDE.md 文件中。

DISTILLED_AESTHETICS_PROMPT = """

<frontend_aesthetics>

你倾向于收敛到通用的、“符合分布”的输出。在前端设计中，这就造成了用户所说的“AI 糙活”（AI slop）美学。请避免这一点：打造有创意、有辨识度的前端，让人眼前一亮、心生愉悦。重点关注：

排版：选择美观、独特、有趣的字体。避免使用 Arial 和 Inter 这类通用字体；转而选择有个性的字体，提升前端的美学品质。

色彩与主题：确立统一的美学风格。使用 CSS 变量保持一致性。以主色为主、辅以鲜明点缀色的搭配，优于怯懦、均匀分布的色板。可从 IDE 主题和文化美学中汲取灵感。

动效：用动画实现效果和微交互。HTML 优先采用纯 CSS 方案。React 在可用时使用 Motion 库。聚焦高影响力的时刻：一次精心编排、带有错落呈现（animation-delay）的页面加载，比零散分布的微交互更能带来愉悦感。

背景：营造氛围与层次感，而不是默认使用纯色。叠加 CSS 渐变，使用几何图案，或添加与整体美学相契合的上下文效果。

避免千篇一律的 AI 生成美学：

- 被滥用的字体族（Inter、Roboto、Arial、系统字体）

- 陈词滥调的配色方案（尤其是白底紫色渐变）

- 可预测的布局和组件模式

- 缺乏针对具体情境个性的流水线式设计

以创造性的方式诠释需求，做出出人意料的选择，让设计真正贴合上下文。在亮色与暗色主题、不同字体、不同美学风格之间做出变化。你仍然倾向于在多次生成中收敛到常见选择（例如 Space Grotesk）。请避免这一点：跳出思维定式至关重要！

</frontend_aesthetics>

"""

import html

import os

import re

import time

import webbrowser

from datetime import datetime

from pathlib import Path

from anthropic import Anthropic

from IPython.display import HTML as DisplayHTML

from IPython.display import display

client = Anthropic(api_key=os.environ.get("ANTHROPIC_API_KEY"))

def save_html(html_content):

os.makedirs("html_outputs", exist_ok=True)

timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")

filepath = f"html_outputs/{timestamp}.html"

with open(filepath, "w") as f:

f.write(html_content)

return filepath

def extract_html(text):

pattern = r"```(?:html)?\s*(.*?)\s*```"

matches = re.findall(pattern, text, re.DOTALL)

return matches[0] if matches else None

def open_in_browser(filepath):

abs_path = Path(filepath).resolve()

webbrowser.open(f"file://{abs_path}")

print(f"🌐 Opened in browser: {filepath}")

def generate_html_with_claude(system_prompt, user_prompt):

print("🚀 Generating HTML...\n")

full_response = ""

start_time = time.time()

display_id = display(DisplayHTML(""), display_id=True)

with client.messages.stream(

model="claude-sonnet-5-5",

max_tokens=64000,

system=system_prompt,

messages=[{"role": "user", "content": user_prompt}],

) as stream:

for text in stream.text_stream:

full_response += text

escaped_text = html.escape(full_response)

display_html = f"""

<div id="stream-container" style="border: 2px solid #667eea; border-radius: 8px; padding: 16px; background: #f8f9fa; max-height: 500px; overflow-y: auto;">

<pre style="margin: 0; font-family: monospace; font-size: 12px; color: #2d2d2d; white-space: pre-wrap; word-wrap: break-word;">{escaped_text}</pre>

</div>

<script>

requestAnimationFrame(() => {{

const container = document.getElementById('stream-container');

if (container) {{

container.scrollTop = container.scrollHeight;

}}

}});

</script>

"""

display_id.update(DisplayHTML(display_html))

elapsed = time.time() - start_time

escaped_text = html.escape(full_response)

final_html = f"""

<div style="border: 2px solid #28a745; border-radius: 8px; padding: 16px; background: #f8f9fa; max-height: 500px; overflow-y: auto;">

<pre style="margin: 0; font-family: monospace; font-size: 12px; color: #2d2d2d; white-space: pre-wrap; word-wrap: break-word;">{escaped_text}</pre>

</div>

"""

display_id.update(DisplayHTML(final_html))

print(f"\n✅ Complete in {elapsed:.1f}s\n")

html_content = extract_html(full_response)

if html_content is None:

print("❌ Error: Could not extract HTML from response.")

raise ValueError("Failed to extract HTML from Claude's response.")

filepath = save_html(html_content)

print(f"💾 HTML saved to: {filepath}")

open_in_browser(filepath)

return filepath

单项提示词设计

完整的美学提示词适用于一般场景，但有时你需要更有针对性的控制。你可以单独拎出某些维度（排版、色彩、动效），或锁定某个特定主题。这样生成速度更快，输出也更可预测。

示例 1：仅排版

当你想改进某一个方面而不改动其他部分时，可以单独指定一个设计维度：

TYPOGRAPHY_PROMPT = """

<use_interesting_fonts>

Typography instantly signals quality. Avoid using boring, generic fonts.

**Never use:** Inter, Roboto, Open Sans, Lato, default system fonts

**Impact choices:**

- 代码美学：JetBrains Mono, Fira Code, Space Grotesk

- 编辑风格：Playfair Display, Crimson Pro, Fraunces

- 创业公司风格：Clash Display, Satoshi, Cabinet Grotesk

- 技术风格：IBM Plex 系列, Source Sans 3

- 独特个性：Bricolage Grotesque, Obviously, Newsreader

**搭配原则：** 高对比才有趣。展示字体 + 等宽字体，衬线体 + 几何无衬线体，同一可变字体跨越不同字重。

**用极端值：** 字重用 100/200 对比 800/900，而不是 400 对比 600；字号跳跃 3 倍以上，而不是 1.5 倍。

选定一款有辨识度的字体，果断使用。从 Google Fonts 加载。编码前先说明你的选择。

</use_interesting_fonts>

"""

# Generate with typography-only guidance

generate_html_with_claude(BASE_SYSTEM_PROMPT + "\n\n" + TYPOGRAPHY_PROMPT, USER_PROMPT)
